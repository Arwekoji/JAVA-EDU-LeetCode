Каждая задача из LeetCode должна быть реализована внутри одного пакета для демонстрации чистого понимания
Один класс называется Tests: 
  В нём обязательно должен быть метод runAll() со списком всех микротестов и try catch в цикле for.
  Остальные подметоды должны являться чистыми boolean тестами, сравнивающими результат с внутренним датасетом
