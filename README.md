Каждая задача из LeetCode должна быть реализована внутри двух пакетов для демонстрации чистого понимания  
  
Архитектура LeetCode проектов:
src
-base             // Неизменяемый пакет оболочки. Меняется только Settings  
--Main.class          // Исключительно запуск Testing.runAll()  
--Utils.class         // Набор вручную написанных абстрактных методов, применимых не только в заданной задаче  
--Design.class        // Визуальные паттерны для оформления вывода задачи  
--Testing.class       // Запуск тестов через for-try-catch и оформление ошибок  
-task             // Пакет с алгоритмами самой задачи  
--... Algorhytmes ...  
--Tests.class        // Набор boolean методов-тестов, список ожидаемых выводов и константы с описанием задачи
